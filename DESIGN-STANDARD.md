# MaiCareNow Website Design Standard

MaiCareNow is a guided visual story, not a traditional healthcare website.

- Warm, professional, family-centered healthcare navigation brand.
- Soft cartoon / hand-drawn illustration style.
- Visual-first, minimal text, clear next steps.
- Mai is the recurring guide character.
- Use actual image assets for illustrations. Do not recreate cartoon characters with CSS drawings.
- Homepage starts the story.
- Each story block links to a focused page.
- All Get Started buttons link to: https://tally.so/r/7RMJy9

Approved homepage blocks:
1. Something Changed -> something-changed.html
2. How It Works -> how-it-works.html
3. Lower Prescription Costs -> lower-prescription-costs.html
4. Independent Living & Technology -> independent-living-technology.html
5. Care Reports & Guidance -> care-reports.html
6. Resources You Can Trust -> resources.html
7. About MaiCareNow -> about.html
8. Contact & Support -> contact.html
