MaiCareNow GitHub Upload Package

Upload all files and the assets folder to the ROOT of your GitHub Pages repository.

Included pages:
- index.html
- how-it-works.html
- services.html
- resources.html
- about.html
- blog.html
- intake.html
- thank-you.html
- login.html
- contact.html
- privacy.html
- terms.html
- 404.html
- assets/style.css

Tally setup:
1. Open intake.html in GitHub.
2. Replace the placeholder form box with your Tally embed code.
3. In Tally, set redirect after submission to:
   https://maicarenow.com/thank-you.html

Note:
assets/homepage-design-reference.png is included as the visual reference for the homepage direction you liked.
