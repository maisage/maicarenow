# MaiCareNow Design Standard

The homepage hero is the main visual story.

Rules:
- The hero image is the homepage anchor.
- Links are clickable hotspot overlays on the hero.
- Do not place the story blocks beside the hero.
- Do not recreate the approved illustration with CSS drawings.
- Use actual image assets.
- All Get Started buttons link to https://tally.so/r/7RMJy9
